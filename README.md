# 📚 Smart Study Planner

## About the Project
Smart Study Planner is a simple Python-based web application developed using Streamlit. It helps students organize their study tasks, create weekly timetables, set daily study goals and monitor their academic progress.

## Features
- Add and manage study tasks.
- Mark tasks as completed.
- Delete unwanted tasks.
- Create a weekly study timetable.
- Set daily study goals.
- Record daily study hours.
- View study progress through graphs.
- Download study reports in CSV format.
- Save tasks and study history.

## Technologies Used
- Python
- Streamlit
- Pandas
- JSON

## Installation

Install the required libraries:

```bash
pip install streamlit pandas
```

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

```bash
py -m streamlit run app.py
```

4. Open the local URL displayed in the terminal.
